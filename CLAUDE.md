# CLAUDE.md

## Workflow rule — PR + approval required
No change may be pushed directly to any branch in this repository —
not even `master`, not even a one-line fix. Every change (code,
config, docs, including this file) must go through a pull request, and
the repository owner must explicitly approve it before it is merged.
Do not merge on your own judgment, even if CI is green and the diff
looks obviously correct. This applies to all Claude Code sessions
working on this repo.
